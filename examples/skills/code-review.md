# 代码审查技能

当被要求审查代码时，按以下步骤进行：

1. **通读改动**：用 `grep`/`read_file` 找到相关文件，理解上下文与调用方。
2. **检查正确性**
   - 边界条件：空值、空数组、越界、并发
   - 错误处理：是否有未捕获的异常、静默失败
   - 资源：文件句柄、子进程、定时器是否释放
3. **检查安全性**
   - 是否有命令注入 / 路径穿越 / 未校验输入
   - 是否有硬编码密钥
   - 权限边界是否被绕过
4. **检查可维护性**
   - 命名是否清晰、函数是否过长
   - 是否有重复逻辑可以抽取
   - 是否引入了不必要的依赖
5. **输出格式**
   - 严重程度：🔴 阻断 / 🟡 建议 / 🟢 提示
   - 每条给出：位置（file:line）、问题、修改建议
   - 最后给一句总体评价

不要吹毛求疵；只报告真正影响正确性、安全或可读性的问题。
